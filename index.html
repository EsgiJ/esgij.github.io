Project Description:

Luden is a general-purpose C++20 game engine built around a custom Entity-Component System and data-oriented design. It has an ImGui-powered editor inspired by Unity and Unreal, Box2D 3.0 physics, and a hot-reload capable native scripting system.

When I started I had little C++ experience and no idea how engines actually worked: how to design systems, manage memory efficiently, or build editor tools. Building Luden taught me all of it, and it is where I put the low-level habits I picked up at IO Interactive into practice.

Architecture:

  • Engine.dll holds the ECS, physics, rendering and resource management. It depends on nothing else.
  • Editor.exe is the ImGui editor: scene hierarchy, inspector, viewport and resource browser.
  • GameModule.dll holds the game scripts, compiled separately and hot-reloadable.

Dependencies flow one way, so the engine can be reused across projects.

What I Built:

  • Entity-Component System hand-built from scratch, not a third-party library like EnTT, so that I would actually understand engine internals. Entities are lightweight IDs and components of one type live contiguously in memory, which keeps iteration cache-friendly across thousands of entities.
  • Performance work on cache-friendly data layouts and manual memory management.
  • Hot reload. When the game DLL changes, the editor destroys script instances, unloads the old DLL, loads the new one, then re-registers and recreates instances without restarting.
  • Editor tabs. Scene (gizmos, play and edit toggle, physics debug draw), Sprite (atlas slicing), Animation (frame timeline), Prefab (nested templates that auto-update every instance).
  • Physics through Box2D 3.0, with static, dynamic and kinematic bodies.
  • Input as a context-based system with action abstraction, inspired by Unreal's Enhanced Input.
  • Serialization in a JSON scene format, chosen to be version-control friendly.

Shipped With Luden:

The Deranged Penguin, a game about a penguin manipulating its friends at the zoo in pursuit of eternal peace, made at Global Game Jam 2026. Thanks to İclal Baydur and Ataberk Akın, who used my buggy engine and shipped a game with it despite missing features and unclear documentation.

Project Description:

A C++ and Dear ImGui tool for visualizing and debugging Hierarchical Task Network (HTN) AI trees.

This is a personal, independent version of a tool concept I worked on during my AAA experience at IO Interactive. It is built with its own architecture and contains no proprietary code or assets.

Features:

  • Node hierarchy view with search and jump-to-source navigation, plus a live, draggable node graph of task decomposition.
  • Real-time property inspector for tuning task parameters such as engagement range and thresholds.
  • Mini map for fast navigation on larger trees.
